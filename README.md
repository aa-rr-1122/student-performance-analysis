Students Performance Analysis
About the Project
This project focuses on analyzing students’ academic performance using Python. It explores mathematics, reading, and writing scores to identify performance patterns and compare results across different groups.
Objectives
• Analyze students’ academic performance.
• Calculate average scores for each subject.
• Identify the top 10 and bottom 10 students based on their average scores.
• Compare academic performance by gender.
• Analyze the relationship between test preparation and students’ scores.
• Visualize score distributions using charts.

Tools & Technologies

• Python
• Pandas
• Matplotlib
• Seaborn
• Jupyter Notebook

Key Analysis

• Data exploration and descriptive statistics.
• Average score calculations.
• Student performance ranking.
• Gender-based performance comparison.
• Test preparation course analysis.
• Data visualization using box plots.

Skills Demonstrated

• Data Analysis
• Exploratory Data Analysis (EDA)
• Data Manipulation
• Statistical Analysis
• Data Visualization
• Python Programming

Conclusion

This project demonstrates how data analysis techniques can be used to explore educational data, identify performance patterns, and gain insights into students’ academic results.
